typedef uint32_t PulseVideoMixInputID

Opaque identifier for a video input source.

Obtained from one of the Pulse input APIs:

  • pulse_video_mix_input_from_device()

  • pulse_video_mix_input_from_file()
  • pulse_video_mix_input_from_data_session()

The caller is responsible for the lifecycle of the underlying source. The mix session borrows the input for the duration of the mix.

◆ pulse_video_mix_connect()

PulseError pulse_video_mix_connect ( Pulse *  client,
const PulseVideoMixConfig *  config,
PulseMediaContent  media_content 
)

Connect (start) a video mix session.

Sets up a compositing pipeline described by config and attaches it to media_content. Any previously connected video source on the same media_content will result in PULSE_ERROR_UNEXPECTED_STATE, so disconnect must be called first.

Parameters
clientThe Pulse handle.
configThe video mix configuration describing all layers.
media_contentThe media content slot to attach the mix to (e.g. PULSE_MEDIA_CONTENT_MAIN).
Returns
PULSE_SUCCESS (0) on success, or a PulseError code on failure.
