◆ pulse_app_transport_push()

PulseError pulse_app_transport_push ( Pulse *  client,
const uint8_t *  data,
size_t  size 
)

Feed an inbound (muxed RTP/RTCP) packet into the client.

Companion to pulse_options_set_app_transport(). The application calls this function with each packet it has received from its own transport (e.g. a WebSocket tunnel), to deliver it into the client's receive pipeline.

Thread-safe: may be called from any thread, including synchronously from inside the PulseAppPacketCallback that the client uses for outbound packets (i.e. loopback usage is safe).

The data buffer is borrowed for the duration of the call; the implementation copies the bytes it needs to retain.

Parameters
clientThe Pulse handle.
dataPointer to a muxed RTP/RTCP packet.
sizeLength of data in bytes.
Returns
PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.
