Detailed Description

Describes a single input slot in a video mix composition.

This struct describes where and how an input appears in the composition. It does NOT describe the source — that is identified solely by input_id, which the caller obtained from a pulse_video_mix_input_from_*() function.

Fields:

  • input_id An input previously obtained via pulse_video_mix_input_from_device() or similar.
  • layer Layer index (0-based). Same layer = same grid.
  • width_ratio Fraction of layer width (0.0–1.0).
  • height_ratio Fraction of layer height (0.0–1.0).
  • x_centrepoint Horizontal anchor (0.0=left, 0.5=center, 1.0=right).
  • y_centrepoint Vertical anchor (0.0=top, 0.5=center, 1.0=bottom).
  • videoproc_mask Per-input video processing (segmentation, blur).
