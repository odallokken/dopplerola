pulse_rtp_session_connect_video_output Connects an RTP video output session for the specified media content.

If a session is already active for the content slot, it will be disconnected first and replaced by the new configuration.

Parameters
clientThe Pulse handle.
media_contentThe media content slot to use (MAIN or PRESENTATION).
configThe RTP video output configuration.
Returns
PULSE_SUCCESS on success, or a PulseError code on failure.
